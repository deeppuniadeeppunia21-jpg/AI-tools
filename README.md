## 📸 App Preview

![Punjab AI Tools Preview](images/app-preview.png)
Punjab AI Photo & Video Maker 🚀

A neon-themed, Android-friendly photo editor and slideshow maker built with HTML, CSS, and JavaScript.

✨ Features

📸 Photo Maker

- Select a photo from your device
- Adjust brightness, contrast, and saturation
- Rotate photos
- Save edited photos as PNG

🎬 Video Maker

- Select multiple photos
- Create a photo slideshow
- Choose portrait, landscape, or square format
- Add custom text to the slideshow
- Preview and download the generated video when supported by your browser

🎨 Design

- Neon blue and purple gaming style
- Dark interface
- Mobile-friendly layout
- Responsive design

🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Canvas API
- MediaRecorder API

🚀 Run the App

1. Download or clone this repository.
2. Open "index.html" in a compatible browser or use the Acode editor on Android.
3. Select photos and try the editing tools.

🌐 Publish with GitHub Pages

1. Upload "index.html" to the root of your GitHub repository.
2. Open Settings → Pages.
3. Select Deploy from a branch.
4. Choose the "main" branch and "/ (root)".
5. Press Save and wait for deployment.

🤖 About AI

This starter version provides browser-based photo editing and slideshow creation. It does not generate new AI images or AI videos yet. Genuine AI generation requires an AI model or service and, where needed, a secure backend.

Security: Never expose private API keys in client-side HTML or JavaScript.

📱 Android and Play Store

This project is currently a web app, not a ready-to-upload Android App Bundle (".aab"). Additional Android packaging, testing, privacy disclosures, and Google Play policy compliance are required before publishing.
